#### 🚧 Install cnpm, yarn

- Copy the code (run in desktop cmd) `npm install -g pnpm`

#### 🏭 Browser Support

| Edge      | Firefox      | Chrome      | Safari      |
| --------- | ------------ | ----------- | ----------- |
| Edge ≥ 88 | Firefox ≥ 78 | Chrome ≥ 87 | Safari ≥ 13 |

> Since Vue3 no longer supports IE11, ElementPlus also does not support IE11 and earlier versions.

#### ⚡ Usage Instructions

It is recommended to use pnpm, as yarn sometimes causes errors. <a href="https://nodejs.org/en/" target="_blank">Node version > 14.18+/16+</a>

> Vite no longer supports Node 12 / 13 / 15, as these versions have reached their End Of Life (EOL) stage. You must now use Node version 14.18+ / 16+.

```bash
# Install dependencies
pnpm install

# Run
pnpm run dev

# Build
pnpm run build
```
