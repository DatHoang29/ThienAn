### Khung `Send*Async` lặp 7 lần trong `VwISAPIDeviceClient`

Bảy hàm gửi khác nhau ở đúng ba điểm: HTTP method, cách tạo `Content`, cách đọc kết quả (`Deserialize<T>` XML / `JsonSerializer` / `ReadStatus` / `ReadAsByteArrayAsync`). Phần còn lại giống nhau từng dòng:

```csharp
var ip = controller.IP;
if (IsCircuitBreakerBlocked(ip, out var remaining))
    return VwISAPIResult<T>.Fail(CircuitBreakerMessage(controller, remaining), 429);
try
{
    using var request = CreateRequest(HttpMethod.X, controller, relativeUri);
    using var response = await _httpClient.SendAsync(request, ct);
    var content = await response.Content.ReadAsStringAsync(ct);
    if (!response.IsSuccessStatusCode)
    {
        RecordCircuitBreakerFailure(ip, (int)response.StatusCode);
        return VwISAPIResult<T>.Fail($"HTTP {(int)response.StatusCode} {response.ReasonPhrase}", ...);
    }
    RecordSuccess(ip);
    // ← chỉ dòng này khác nhau
}
catch (Exception ex)
{
    _logger.LogError(ex, "Error calling ISAPI ... {Uri} on controller {Ip}", relativeUri, ip);

}
```
