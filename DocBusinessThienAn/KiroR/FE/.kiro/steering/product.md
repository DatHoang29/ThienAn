# Product Overview

## TAC Web Core (tacwebcore)

An Intelligent Transport System (ITS) web application for traffic management and monitoring. The platform provides a comprehensive dashboard for managing transportation infrastructure.

### Core Modules

- **TMS (Traffic Management System)** - Traffic monitoring, incident management, and map-based visualization
- **VMS (Variable Message Sign)** - Electronic signboard management and content control
- **FMS (Fleet Management System)** - Vehicle fleet tracking and management
- **Big Screen Display** - Full-screen dashboard for control room monitoring with map visualization

### Key Features

- Real-time map visualization using Leaflet and MapLibre GL
- Live camera streaming integration (EZUIKit, JSMpeg)
- Dynamic routing controlled by backend API
- Multi-language support (Vietnamese default, English)
- Real-time data via SignalR, MQTT, and NATS WebSocket
- Document viewing (PDF, Excel, Word)
- Advanced data tables with VxeTable

### User Interface

- Element Plus and PrimeVue component libraries
- Dark/light theme support
- Responsive layout for various screen sizes
- Full-screen mode for control room displays
